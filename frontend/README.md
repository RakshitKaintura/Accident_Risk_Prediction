# SafeRoute Frontend

React + Vite frontend for SafeRoute Bengaluru.

## Features

- Interactive Leaflet map with Bengaluru accident heatmap
- Click-to-analyze location risk
- Place search and route search
- High-risk route segment highlighting
- Responsive dashboard with live risk context (traffic + weather)

## Environment

Create `frontend/.env`:

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
